
# 🚍 SmartRouteADMM - AI-Driven Bus Scheduling and Route Management System

SmartRouteADMM is an AI-based dynamic bus scheduling and route optimization project built using LSTM forecasting and ADMM optimization. The system adapts to real-time passenger demand using IR sensor data and makes routing decisions via a space-time-state network.

## 📌 Key Features
- Forecasts bus demand using LSTM neural networks.
- Uses ADMM (Alternating Direction Method of Multipliers) for scalable optimization.
- Real-time passenger monitoring via IR sensors and Arduino.
- Frontend dashboard developed using ReactJS for live visualization.

## 🛠 Tech Stack
- Python, Jupyter Notebook, LSTM, ADMM
- Arduino Mega, IR Sensors
- ReactJS (frontend)
- Matplotlib, NumPy, Pandas
